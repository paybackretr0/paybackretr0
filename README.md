## 02 · The 3D stage

The banner at the top is a **real perspective render** of the room that greets you on the portfolio: one shaft of light, dust in the air, a pool of it on the floor, and a camera that drifts with a single slow sine. It is baked frame by frame from 3D geometry into an SVG — GitHub will not run WebGL in a README, so the geometry is projected on the server side instead of in your browser.
